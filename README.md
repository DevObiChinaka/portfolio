# DevObi Portfolio

Personal portfolio website for showcasing selected software projects, technical interests, and contact information.

**Live portfolio:** https://devobichinaka.vercel.app

## Built With

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Heroicons and Lucide React

## Getting Started

### Prerequisites

- Node.js compatible with the installed Next.js version
- npm

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Available Scripts

| Command | Purpose |
| --- | --- |
| `npm run dev` | Start the local development server |
| `npm run build` | Create a production build |
| `npm run start` | Serve the production build |
| `npm run lint` | Run ESLint |

## Project Structure

- `app/` — Next.js application routes and layout
- `components/` — reusable interface components
- `public/` — static assets, if present

## Deployment

The site is deployed at the live portfolio URL above. For deployment configuration, refer to the platform and project settings used by the maintainer.
